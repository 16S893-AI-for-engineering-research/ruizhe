# Ruizhe Huang — portfolio

A small, multi-page personal portfolio built with plain HTML, CSS, and JavaScript.

## Pages

- `index.html` — introduction and selected skills
- `about.html` — background and contact details
- `projects.html` — project outline / selected work

## Run locally

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Before publishing

Replace the sample email address (`hello@example.com`) and project copy with your own details. The pages are static, so they can be hosted on GitHub Pages, Netlify, or any basic web host.

## Details

- The orbital illustration, ticker, reveal transitions, and cursor glow provide motion.
- Type `hello` anywhere on the site to reveal the hidden Easter egg.
- The site uses the Space Grotesk and DM Mono fonts from Google Fonts.
